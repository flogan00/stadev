## <b>stadev</b>
### Description
This repository stores qualitative archival data from Phoenix-area news publications regarding the development of Cardinals Stadium (now State Farm Stadium). The goal is to understand how developers fostered relationships with public and private actors and how those relationships resulted in the stadium's development outcomes across municipalities.

This repository is associated with a presentation I gave at the 2026 Swiss Geoscience Meeting, titled "Relationships, public financing, and urban development outcomes: The case of Cardinals Stadium in Arizona, USA." Here is the abstract for the project:
<blockquote> The development of Cardinals Stadium (now State Farm Stadium), a National Football League arena in Glendale, Arizona, spanned fifteen years, from 1988 to its groundbreaking in 2003. During this period, several municipalities competed to host the publicly funded stadium. The project’s public financing structure shaped relationships between developers and public and private actors, such as stadium executives, city council members, taxpayers, and community activists. These relationships took place across municipalities in the Phoenix metropolitan area to negotiate the approval of the Cardinals Stadium development project. Public actors in particular became directly involved in the development timeline, as, if their municipality was chosen to host the stadium, they would assume substantial financial responsibility for the project. Although numerous factors determined the selection of the host municipality, this presentation specifically examines how relationships between public actors and the stadium development influenced the development process and which municipality was chosen. 


Using archival methods, I analyze the discourses published in local and national print news media between 1988 and 2003 that document and characterize the dynamic relationships between public actors across potential host municipalities and the stadium development. I trace how those different relationships across municipalities impacted the financial development outcomes and the spatio-temporal trajectory of those outcomes in the urban landscape. This presentation seeks broadly to shed light on the role of relationships in the timing of decisions in financing urban megaproject developments, suggesting new perspectives for understanding the contributions of public actors to those decisions. </blockquote>

### What are the files
data-dictionary.csv -> This file defines all of the variables used in the following files.

data/coding.csv -> This file attributes excerpts with codes, including some memos.

data/codebook.csv -> This file defines all of the codes inductively derived from the newspaper excerpts.

data/sources.csv -> This file summarizes all of the newspaper publications that excerpts were sourced from.

data/excerpts.csv -> This file contains all of the newspaper excerpts included in analysis.
